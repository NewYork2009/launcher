# Tetris — классический тетрис

Тёмный тетрис с плавным падением, ускорением по уровням, счётом и рекордом
(рекорд сохраняется между запусками в `~/.tetris_record.json`).

## Запуск

Нужен Python 3.9+ (на Windows отметь «Add to PATH» при установке) — больше
ничего ставить не нужно, только стандартная библиотека.

```bash
python main.py
```

### Без консоли (Windows)

Двойной щелчок по **Tetris.bat**.

## Клавиши

| Клавиша | Действие |
| ------- | -------- |
| ← / → | двигать фигуру |
| ↓ | ускорить падение |
| ↑ / X | поворот |
| Z | поворот назад |
| Space | мгновенно вниз |
| P | пауза |
| R | начать заново |
| Esc | выход |

## Очки

1 линия — 100, 2 — 300, 3 — 500, 4 (тетрис!) — 800. Каждый спуск — +1,
мгновенный спуск — +2 за клетку. Каждые 10 линий — новый уровень, скорость растёт.
