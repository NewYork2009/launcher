# Сапёр — тёмная классика с рекордами

Классический «Сапёр» на тёмной теме: безопасный первый клик (мины появляются
после него и не встанут под руку), флажки правой кнопкой, автокрытие пустых
полей, таймер и **рекорд времени** для каждого уровня сложности
(хранится в `~/.minesweeper_best.json`).

## Запуск

Нужен только Python 3.9+ (tkinter уже встроен, зависимостей нет):

```bash
python main.py
```

### Без консоли (Windows)

Двойной щелчок по **Minesweeper.bat**.

## Управление

| Действие | Как |
| -------- | --- |
| открыть клетку | левый клик |
| поставить флажок | правый клик |
| открыть соседей цифры | левый клик по уже открытой цифре, когда флажков вокруг ровно её число (chord) |
| новая игра | кнопка «Новая» или `N` |
| сложность | кнопки сверху или клавиши `1` / `2` / `3` |

## Сложности

- Легко: 9×9, 10 мин
- Средне: 16×16, 40 мин
- Сложно: 16×30, 99 мин
