# Launcher — быстрый лаунчер по хоткею

Окно как Spotlight на Mac: нажал хоткей — набрал пару букв — получил результат.
Пишешь `ptys` → открывает приложение, `2+2*10` → отвечает калькулятором,
`g котики` → ищет в Google, `yt трек` → YouTube, `gh repo` → GitHub, `w запрос` → Википедия.

## Что умеет

- 🔎 Мгновенный поиск по установленным приложениям: сканирует меню «Пуск»
  (Windows), `.desktop`-файлы (Linux) или `/Applications` (macOS)
- 🧮 Калькулятор прямо в строке: `2+2*10`, `(5-1)/4`, `2^10` — ответ уже в результатах
- 🌐 Веб-ярлыки: `g`, `yt`, `gh`, `w` + поисковый запрос, либо набери домен (`github.com`)
- 🔝 Умное ранжирование: точное совпадение выше, недавние запуски поднимаются наверх
- 🕒 История запусков (последние 20) сохраняется локально в `~/.syslauncher.json`

## Запуск

Нужен Python 3.9+ (на Windows при установке отметь «Add to PATH»).

```bash
pip install -r requirements.txt   # одна библиотека — keyboard, для хоткея
python main.py
```

На Windows/macOS tkinter уже встроен. На Linux: `sudo apt install python3-tk`.
На Linux под X11 хоткей работает из коробки; на Wayland глобальные хоткеи
ограничены системой — держи окно открытым.

## Клавиши

| Клавиша | Действие |
| ------- | -------- |
| `Ctrl+Alt+Space` | показать / скрыть окно (нужен пакет `keyboard`) |
| ↑ / ↓ | выбрать результат |
| `Enter` | открыть выбранное |
| `Esc` | скрыть окно (или выход, если хоткей не активен) |
